# AuthKeeper

Privacy Policy and Terms of Service for the AuthKeeper Google OAuth application.

This site hosts the legal pages required for Google OAuth app verification:
- [Privacy Policy](https://zendryn.com/#privacy)
- [Terms of Service](https://zendryn.com/#terms)

## Purpose

AuthKeeper is a utility application that manages OAuth authentication tokens for the account owner's Google services. This static site provides the privacy policy and terms of service required to publish the Google OAuth app, which removes the 7-day refresh-token expiry imposed on unverified test apps.

## Deployment

Hosted on GitHub Pages. The site is served from the `main` branch root.

## Domain

Custom domain: `zendryn.com` (configured in GitHub Pages settings, DNS managed in AWS Route 53).
